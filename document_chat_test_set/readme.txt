This folder is a synthetic, cross-format document set designed to test a document-chat and retrieval system. It describes a fictional vendor relationship between Northstar Manufacturing and Acme Industrial Supplies Ltd., centered on purchase order PO-1042. The Markdown policy states a 30-day refund window and Net-30 payment terms; the PDF contract records Acme as the vendor, PO-1042 as the purchase order, and 2024-03-01 as the signing date; the XLSX contains Q3 invoice rows including two invoices for PO-1042; the CSV provides region totals that reconcile to the spreadsheet; the PowerPoint explicitly notes that Acme paid twice on PO-1042; the PNG is a visual invoice containing PO-1042 and a $12,500.00 amount; and reconcile.py contains a function for detecting duplicate po_id values. The files intentionally repeat key facts across different formats so a document-chat system can be tested for cross-document retrieval, entity resolution, numeric reconciliation, image/OCR extraction, and code understanding. All data is fictional.
